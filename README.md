## How I work

- **Evidence first:** investigate the code and data, write a plan with evidence behind every step, get it reviewed, then implement.
- **Non-breaking by default:** new endpoints run alongside old ones, feature flags make rollback instant, and schema changes only ever add.
- **AI-accelerated, human-verified:** I drive AI coding agents (Claude Code) through a review-gated workflow. The agent never certifies its own work: every change is compiled, tested and reviewed.
- **Tests against real infrastructure:** integration tests run on real PostgreSQL for financial logic.
